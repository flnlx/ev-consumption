# 纯电汽车电耗统计

记录每次充电，了解实际电耗、用车成本和估算续航。支持免费充电、同一天多次充电，以及月度、季度、年度统计。

## 选择适合你的版本

| | 网页版 | Excel 版 |
| --- | --- | --- |
| 适合谁 | 希望手机录入、多设备查看 | 希望在电脑上离线使用 |
| 使用方式 | 浏览器访问，需要账号和邀请码 | 下载后用 Microsoft Excel 打开 |
| 数据保存 | 登录后点击保存，数据存到云端 | 保存在自己的 Excel 文件中 |
| 记录数量 | 不设固定条数上限，受存储及免费额度限制 | 每份表格最多 500 条 |
| 分期查看 | 拖动月份范围，可跨年查看 | 选择年份及月度、季度、年度 |

两个版本使用相同的基本统计口径，界面和功能范围有所不同。

## 开始使用

**网页版：** 打开 [电耗手账](https://ev-consumption.pages.dev/)，向站点管理员获取邀请码，注册后即可使用。邀请码只能成功注册一次。

**Excel 版：** 前往 [下载页面](https://github.com/flnlx/ev-consumption/releases/tag/excel-B20261001)。

- 推荐下载 **完整 ZIP 压缩包**，解压后打开其中的 Excel 文件。它还包含使用说明、测试报告和数据备份工具；备份工具适用于 Windows。
- 只需要录入和统计，也可以单独下载 `.xlsx`。表格不需要启用宏。

## 怎么记录一次充电

1. 先填写车辆的电池容量和标称续航。
2. 每次充电结束后，填写日期、仪表上的**累计里程**、充电量和金额。累计里程不是本次行驶里程；免费充电金额填 `0`。
3. 充到 **100%** 时选择“是”；只充到日常设置的 80% 等上限时选择“否”。
4. 同一天可以填写多条，按实际先后顺序录入，累计里程可以相同，但不能减少。
5. 网页版点击“保存修改”，Excel 版保存工作簿。网页版的红色“有未保存修改”表示修改还未保存。

网页版默认把最近录入的记录放在前面，可以切换记录序号正序、倒序。新增记录会自动定位到输入框，即使记录已超过一页，也不需要手动找最后一页。

## 怎么看统计

**充满区间统计**适合观察电耗：至少需要两次充满，合计这两次之间的充电量与里程。第一次充满时的充电量不计入，第二次及中间的补电计入。

**全部记录累计估算**适合看长期趋势：从第一条充电结束开始计算，首尾剩余电量不同会带来误差。

在网页版的“分期统计”中，拖动开始、结束月份滑块即可跨年查看，也可精确选择月份。四张图共用这个范围，自动调整显示尺度；手机上无需分别拖动每张图。季度、年度只覆盖部分月份时，会标明所统计的月份。

电耗包含充电损耗和停车耗电。等效续航、达成率是估算；跨月的充满区间整体计入结束月份，并不等于精确的自然月电耗。未完成的区间不计入充满区间统计，没有结果时显示空白。

## 保存与备份

- **网页版：** 点击“导出 JSON”下载备份，包含当前页面尚未保存的修改。导入会替换当前页面的数据，检查后再保存；保存导入时会保留替换前的一份数据，可恢复。
- **Excel 版：** 先保存工作簿，再使用完整压缩包里的导出工具。升级表格时，将备份导入新版即可，不需要重新录入。
- Excel 版的备份可导入网页版。网页版超过 500 条或使用新版备份格式时，不能直接导回当前 Excel 版。

建议定期导出备份。网页版需要点击保存，关闭页面前注意是否还有红色提示；如果保存失败，先导出当前修改，保留备份后再重试。
